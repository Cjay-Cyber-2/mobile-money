---
title: 'Stellar SEPs Overview'
description: 'Standardized protocols implemented by the bridge'
---

The Mobile Money Bridge fully implements key Stellar Ecosystem Proposals (SEPs) to ensure seamless interoperability with wallets and exchanges.

- **SEP-10**: Web Authentication
- **SEP-12**: KYC API
- **SEP-24**: Interactive deposit and withdrawal
- **SEP-31**: Cross-border payments
- **SEP-38**: Quotes
